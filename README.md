# Informatica Progetti Web

**Progetti Web Del corso di informatica 5° anno**

---

Questo repository contiene esercizi in HTML5, CSS, JavaScript, PHP.
Le pagine includono esempi pratici e progetti web che coprono diversi argomenti del corso.

---

## Struttura della repository
Ogni cartella è un progetto/esercizio che viene svolto in classe

Informatica_Progetti_WEB<br>
|---Esercizio_1/<br>
|---Esercizio_2/<br>
|---Progetto_1/<br>
|---Progetto_2/<br>
|---...

---

### Contenuti
IL progetto include:
- Pagine `HTML5`
- Alcuni temi `CSS3` ognuno per il proprio progetto
- Script `JavaScript` per l'interattività con la pagina `HTML`
- Script `PHP` per far funzionare le applicazioni lato Server
- Files `JSON` o `CSV` che vengono utilizzati per salvare i dati
